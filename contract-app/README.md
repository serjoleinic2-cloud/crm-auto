# Локальная подготовка договора

Пробная версия для Windows. Создаёт Word-договор и PDF-согласие на локальном устройстве. Не использовать для реальных клиентов до проверки всех страниц, полей и текста. Версия Android и функция «Поделиться» пока не реализованы.

В отдельной папке `contract-app`:

```powershell
npm install
npm start
```

После проверки можно собрать установщик командой `npm run dist`. Во время установки зависимостей нужен интернет; приложение блокирует сетевые запросы. При создании нового договора черновик предыдущего клиента удаляется после подтверждения. В исходном бланке согласия напечатан 2026 год; перед применением проверьте актуальность бланка.

## Обновление на Windows

Закройте приложение и выполните из PowerShell:

```powershell
cd D:\contract-local
git switch feature/local-contract-app
git pull --ff-only origin feature/local-contract-app
cd contract-app
npm install
npm start
```

Если Git сообщает о локальных изменениях, сохраните их перед обновлением. Для проверки обработчиков сохранения: `npm test` в папке `contract-app`.

## Фокус и проверка ввода

После перехода между шагами фокус переходит в первое поле; на шаге проверки — в заголовок. Сообщения об ошибках и сохранении выводятся на странице. «Новый договор» использует встроенный диалог с отменой и Escape. Окна сохранения привязаны к окну приложения; после закрытия фокус возвращается в приложение.

Проверено на Windows в Electron 29.4.6, в отдельном тестовом профиле и только на вымышленных данных:

- Через отладочный интерфейс Electron: щелчки и ввод во всех 27 полях, Tab, переключение шагов, возврат и восстановление черновика после перезагрузки. Для дат проверена клавиша ArrowUp, затем установлены фиксированные значения через событие input для генерации документов.
- Подтверждение нового договора, отмена кнопкой и Escape, повторный Escape после предыдущего подтверждения; ввод после ошибки. Ошибок JavaScript в этих сценариях не обнаружено.
- Реальные обработчики IPC создали DOCX и PDF; проверены подставленные тестовые данные и читаемость файлов. В этом тесте системный выбор пути заменён тестовым обработчиком.
- `npm test`: создание обоих документов, родительское окно диалога, возврат фокуса после сохранения/отмены/ошибки диалога и ошибки обязательных полей (8 проверок).

Ограничения: исходный отказ ввода устойчиво не воспроизведён. Изменения устраняют обнаруженные пробелы управления фокусом, но подтверждённая первопричина исходного сбоя не установлена. Проверка физической мышью через Windows Automation и полноценная проверка системного окна сохранения не завершены: захват окна завершался тайм-аутом. Шаблоны и генераторы документов не изменены.
